# B 提示与交互

## B6 · 提示条弹两次

- **现象**：一次操作连续弹两条提示，或显示时长翻倍。
- **根因**：为凑时长在循环里重复 `show()`；或 toast 与提示条同时触发。
- **正确做法**：`host.toast()` 自带 500ms 防抖；自绘提示条只 show 一次，时长交给 `showMs` / `fadeMs` 控制。
- **自查项**：
  - [ ] 是否有循环里调 show？
  - [ ] 是否混用了系统 Toast？
- **关联**：B7

## B7 · 模块内提示样式不统一

- **现象**：有的页面是白底自绘提示，有的弹系统黑底 Toast。
- **根因**：部分代码直接调用 `Toast.makeText`。
- **正确做法**：模块 UI 内一律 `host.toast()`；只有在目标应用进程里（拿不到 host）才用系统 Toast。
- **自查项**：
  - [ ] ui 层是否还能 grep 到 `Toast.makeText`？
- **关联**：B6
