# E 副作用与稳定性

## E6 · 截图重复

- **现象**：同一次拦截产生多张截图或多条记录。
- **根因**：同一个弹窗多次 show（重建）都触发截图，没有去重。
- **正确做法**：内容哈希 + 5 秒时间窗去重；同标题只保留最新一张。
- **自查项**：
  - [ ] 截图前是否计算了内容哈希？
  - [ ] 是否加了时间窗？
- **关联**：E7

## E8 · hook 异常拖崩目标应用

- **现象**：装模块后目标应用崩溃或闪退。
- **根因**：hook 回调里抛出的异常会被 Xposed 抛给目标进程。
- **正确做法**：每个 hook 的 before / after 全体 try-catch，异常只 `logFramework`，绝不 rethrow。
- **自查项**：
  - [ ] 新 hook 是否整体包裹 try-catch？
  - [ ] catch 里是否只记日志不抛出？
- **关联**：E7

## E9 · 承诺能拦 Unity / Flutter 界面

- **现象**：用户拿去拦游戏或 Flutter 应用的"弹窗"，完全无效。
- **根因**：Unity / Flutter 自绘 UI 不是 Android Dialog，`Dialog.show` 的 hook 抓不到。
- **正确做法**：写进限制说明（帮助页 / 关于页），明确不承诺；只保证原生 Dialog 与 Toast。
- **自查项**：
  - [ ] 能力描述是否写明了不支持自绘 UI？
- **关联**：H4
